# 独立发布验证

以同目录 `results.json` 记录本次实际运行的检查。`evidence/` 提供已移除本机路径和主机名的资源、时序、DRC、仿真与软件测试记录。原始工具工程缓存保留在本地，不作为源码提交。

- 软件自动测试不打开串口。
- Qt 离线自检使用软件寄存器模型，不等于 RTL 仿真。
- `scripts/simulate.tcl` 使用数字芯片模型，不模拟模拟 PLL、输出频率或抖动。
- 综合和实现仅说明相应约束及检查通过，不替代板级时序签核。

独立版本采用 5 MHz 控制时钟。完整采集工程的 10 MHz 封装、初始化表期望值与整卡时序报告不用于证明本仓库版本。报告中历史部署结果与当前独立源码分别标注。
