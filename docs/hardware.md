# 独立示例板级连接

本仓库顶层 `uart_spi_top` 为 HMC7044 配置示例，不包含任何采集数据处理逻辑。示例器件为 KU060，工具版本 Vivado 2024.2；其他板卡需更换目标器件、时钟 IP 和约束。

| 信号 | 引脚或配置 |
| --- | --- |
| 输入参考时钟 | AK17/AK16；200 MHz 差分；DIFF_SSTL12 |
| 控制时钟 | Clock Wizard 输出 5 MHz |
| UART | RX AJ11、TX AM9；115200 / 8N1；LVCMOS33 |
| HMC7044 | CS B20、SCLK D26、SDIO E26、RESET A20；LVCMOS18 |
| 状态 GPIO | H9；LVCMOS18；两级同步后显示原始电平 |

SPI 频率为控制时钟除以 `2 × SPI_HALF_PERIOD`，示例参数为 2，即 1.25 MHz。默认配置表在 `hmc7044_init.v` 中，调度完成后回读 0x000A～0x000E；期望值与表内容成组维护。

启动配置、在线导入文件、实际参考输入和 VCXO 必须匹配。GPIO 的状态含义由芯片 GPO 功能寄存器决定，不能仅凭高电平推断所有 PLL 均已锁定。串口连通性、寄存器回读、锁定和输出频率应分别记录。

仓库没有附带可直接下载的 bit。请先复核实际板卡原理图与 I/O Bank 电压，再由本仓库脚本生成下载文件。不得将其他完整工程的 bit/ltx 当作本独立版本产物。
