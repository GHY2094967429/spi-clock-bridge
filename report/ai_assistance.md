# AI 协作说明

本项目使用 AI 辅助进行模块划分、RTL 和 Qt 编程、异常测试、工程整理及文档编写。以下是协作过程摘要，不作为逐字对话记录，也不包含账户、设备路径或与作品无关的材料。

| 用户需求 | 协作产物 | 核对方式 |
| --- | --- | --- |
| 将桥接工程独立整理 | 核心、协议、板级封装分层及本地构建入口 | 独立工程重建与功能仿真 |
| 使用 Qt 制作图形界面 | 串口线程、寄存器操作、批量和日志 | Qt 事件循环与异常测试 |
| 导入官方 GUI 配置文件 | 静态解析、顺序执行、可选 Restart | 实际 238 条配置逐项模型比对 |
| 串口连接后仍有固定提醒 | 真实模式隐藏横幅、离线模式保留模型说明 | 模式切换及连接回调检查 |
| 上传时不包含采集卡程序 | 文件白名单、干净目录和排除审计 | 目录、模块和依赖检查 |

验证区分软件模型、RTL 仿真、综合实现和真实上板。上位机能连接串口不自动证明寄存器回读、芯片锁定和时钟输出均正确。失败/修正的依据保存在测试与检查流程中；不将未执行的物理测试写成已完成结果。
