# 可复用桥接接入和验证工作流

## 适用范围

适用于具有同步寄存器事务入口和 SPI/SDIO 目标端的 FPGA 配置逻辑。当前已验证的目标格式为 HMC7044。此目录是工程经验与检查流程，不要求安装任何 AI 插件。

## 使用步骤

1. 先定义时钟、复位、请求接受与完成语义；请求载荷保持至 valid/ready 同时为高。
2. 自动配置和在线请求复用一个串行驱动；接受请求时保存来源，完成时只向该来源回复。
3. 在读数据阶段释放 SDIO，并使用目标数字模型检查冲突、位序和完整时钟数量。
4. 以错误 CRC、未知命令、半帧超时、队列满和初始化期间请求验证异常路径。
5. 导入配置按原始顺序执行，不排序、不去重；整份检查通过后才替换预览；超时写入不自动重试。
6. 分别验证串行事务完成、寄存器回读一致和真实时钟工作。软件模型通过不能替代 PLL 锁定或输出测量。

## 经验来源与效果

事务来源和响应分离源于并发访问需要；对应 `sim/tb_bridge.sv` 的来源隔离断言。静态解析及整文件拒收源于官方 GUI 导出为 Python 文件的观察；对应 `host/test_official_config.py`。界面延时及停止流程由 `host/test_gui.py` 检查。

## 失效条件

跨时钟域请求需另加协议；不同芯片需要改变事务格式；动态频率变化需另行协调业务暂停及重新同步。未具备这些条件时，不应直接套用示例或推断板级正确性。
